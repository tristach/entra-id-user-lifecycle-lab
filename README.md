# Microsoft Entra ID User Lifecycle Lab

## Overview

This project demonstrates Microsoft Entra ID user lifecycle administration.

## Skills Demonstrated

- Create users
- Assign groups
- Assign roles
- Reset passwords
- Revoke active sessions
- Review sign-in logs
- Disable accounts
- Delete users

## Environment

- Microsoft Entra ID
- Microsoft Azure
- Microsoft 365
